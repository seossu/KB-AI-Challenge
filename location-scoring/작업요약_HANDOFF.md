## 2. 제품 골격 (확정) — Pull / Push 2단 구조

**하나의 엔진, 두 개의 트리거.**

| | Phase 1 — Pull (입지·자금 설계) | Phase 2 — Push (상권 워치독) |
|---|---|---|
| 계기 | 사용자 조회(온디맨드) | 시스템 감지(월/분기 배치) |
| 대상 | 예비창업자(진입 전) | 운영 중 자영업자(진입 후) |
| 출력 | 입지 Top-N + 금융추천 | 국면변화 경고 + 금융 재추천 |
| KB가치 | 신규 여신 origination | 관계지속·추가여신(LTV) |

- **"동적"의 의미**: ①추천이 1회성 아님(진입 후 지속) ②상권 상태를 "좋다/나쁘다" 고정 아니라 매달 갱신되는 **확률**로 다룸.
- **스코프 정직성**: "실시간"=온디맨드 즉시응답 + 국면은 배치 재추정. 초/일 스트리밍 아님.

## 3. 이론 프레임 (무대 뒤로 한정)

- **Dynamic Capabilities Theory** (Sensing→Seizing→Transforming)를 **서비스 프로세스의 조직 프레임**으로만 사용. "예측 모델"이라 우기지 않음.
- Sensing=Markov Regime-Switching(국면), Seizing=Real Options의 "대기옵션"만 정성 차용, Transforming=금융매칭.
- **중요 교훈(이번 세션)**: 이론 깊이는 "보험"이지 "제품"이 아님. 발표 무대엔 제품(입지+금융 추천)을 올리고, 계량이론은 신뢰성 각주로만. AI다움은 "다양한 데이터 종합분석 + 생성형 근거 리포트"로, "설명가능·화이트박스 AI"로 포지셔닝(금감원 맥락 가점).

## 7. 스코어링 메커니즘 (구현됨)

```
최종점수 = Σ (지표의 '서울 전역 백분위(0~100, 방향통일)' × 가중치)
```
- 백분위: 서울 전체 상권 대비 상대평가. 낮을수록 좋은 지표(경쟁·폐업·임대료)는 100-p로 반전.
- 하드필터(자금 감당불가·주차·평수) → 점수순 정렬 → Top-N → 기여도 분해로 "왜" 생성 → LLM 자연어 추천서.
- **실계산 예(성수역, 예시가중치)**: 점포당매출 86%×0.30=25.7 + 유동인구 88%×0.15=13.2 + 인프라 90%×0.10=9.0 + … = **52.8점**.

### 7.1 가중치 = 3층 구조 (임의 아님)
```
최종가중치 = [1층 baseline] × [2층 개인화] × [3층 위험선호]
```
- **1층 baseline**: **AHP(문헌·CR검증)** 또는 **ML학습(실증)**. ← 임의성 제거 핵심.
- **2층 개인화**: 사용자 priority("낮은 임대료")로 해당 지표 ×부스트.
- **3층 위험선호**: 생존축(폐업·경쟁) vs 수익축(매출·유동인구) 비중.
- scoring.py 는 `base_weights` 주입 가능하게 설계됨 → AHP/ML 가중치 dict 바로 꽂힘.

## 8. ★실증 분석 결과 (지금 데이터로 나온 것)

1. **생존(폐업)은 '경쟁밀도'가 지배.** L1+5foldCV 폐업모델(서울 1,036상권, Q3피처→Q4폐업): 13지표 중 **유사업종수·점포수·유동인구 3개만 선택**, CV AUC 0.77. 지표 더 넣으면 **과적합(0.82→0.73)** — 다중공선성.
2. **번화한 입지요소는 전부 폐업위험↑ (트레이드오프).** 인프라(−0.60)·직장인구(−0.67)·교통·유동인구(−0.49) 모두 생존엔 마이너스. 특히 **유동인구는 폐업위험만 높이고 점포당 생산성 기여 ~0**(corr 0.075).
3. **점포당 매출(생산성)은 입지로 예측 안 됨(R²≈0).** 인구·인프라·교통으로 "내 가게가 얼마 벌지" 예측 실패 → 생산성은 입지 밖(운영·브랜드) 요인.
4. **성수 실측 프로파일(2025 4분기)**:
   | 상권 | 카페수 | 폐업% | 점포당매출 | 생산성(서울%) | 성격 |
   |---|---|---|---|---|---|
   | 성수역 | 56 | 9 | 6,282만 | 상위14% | 고수익·고위험 |
   | 성수초등학교 | 41 | 2 | 4,157만 | 상위24% | 안정·상 |
   | 성수동카페거리 | 40 | 2 | 3,796만 | 상위27% | 안정·중상(밸런스) |
   | 성수1가1동주민센터 | 8 | 9 | 2,303만 | 59% | 저경쟁이나 폐업9%+저매출 |
   | 성수119안전센터 | 18 | 0 | 726만 | 하위25% | 안전하나 저매출 |
5. **결론**: 최적입지 = **생존확률 × 점포당수익 트레이드오프**. 생존만 보면 저경쟁 조용한 곳 선호(성수1가1동), 수익 보면 성수역. → **2목적 스코어**가 진짜 알맹이.

## 9. 미결정 / 다음 단계

1. **AHP 논문 가중치 대기중** — 사용자가 논문의 쌍대비교행렬(또는 최종 가중치)+평가기준 제공 예정. 주면 `ahp.py`로 CR 검증 후 `scoring.base_weights`에 연결. (AHP vs ML 비교 ablation도 예정)
2. **2목적 스코어 구현** — ①생존확률(폐업모델) + ②매출/생산성 모델 결합, 위험선호 슬라이더. (지금 데이터로 바로 가능)
3. **임대료(국토부 data.go.kr 키)** — 사용자 발급 필요. 들어오면 "비용" 축 완성 + 하드필터 강화.
4. **금융추천(Phase 2 후반)** — 자금격차 계산 → 정책자금 RAG(중기부·신보·소진공 크롤링) → LLM 추천서. 아직 미구현.
5. **생성형 리포트** — LLM이 기여도 분해를 자연어 "입지 컨설팅 리포트"로. (AI다움·생성형 소구점)
6. **국면(Regime-Switching)**: 월별 데이터 확보 시 활성화. 현재는 분기 추세 기반 트리거로 대체.
